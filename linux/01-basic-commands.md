Linux Basics – Lesson 01

🎯 Learning Objectives

In this lesson, you will learn some basic Linux terminal commands.

1. Show Current Directory

pwd

Displays the path of your current directory.

2. List Files

ls

Shows files and folders in the current directory.

3. Change Directory

cd Documents

Moves into the Documents directory.

4. Create a Directory

mkdir practice

Creates a new directory named practice.

5. Create a File

touch test.txt

Creates an empty file named test.txt.

6. Display Text

echo "Hello Zarif Cyber Lab"

Prints a message in the terminal.

🧪 Practical Exercise

Try these commands in your own Linux environment:

1. Check your current directory.
2. List the files.
3. Create a directory named "cyber-lab".
4. Enter that directory.
5. Create a file named "hello.txt".

⚠️ Safety Note

Practice these commands only in your own environment. Be careful with commands that delete or overwrite files.
