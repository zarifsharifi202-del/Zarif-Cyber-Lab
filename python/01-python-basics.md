🐍 Python Basics – Lesson 01

🎯 Goal

Learn the basic concepts of Python programming through simple examples.

1. Print

Use "print()" to display text:

print("Hello, Zarif Cyber Lab!")

2. Variables

Variables store information:

name = "Zarif"
age = 20

print(name)
print(age)

3. Basic Math

Python can perform mathematical operations:

a = 10
b = 5

print(a + b)
print(a - b)
print(a * b)
print(a / b)

4. User Input

Use "input()" to receive information:

name = input("Enter your name: ")
print("Welcome", name)

5. If and Else

Use conditions to make decisions:

password_length = 12

if password_length >= 12:
    print("Good password length")
else:
    print("Use a longer password")

🧪 Practice Exercises

1. Print your name.
2. Create two variables and add them.
3. Ask the user for their name.
4. Write a condition to check a number.
