🧪 Practical Labs

New exercises and projects will be added step by step.

⚠️ Safety Notice

All exercises are intended for educational purposes and must be performed only on systems you own or have permission to test.

🚀 Start Learning

Explore the exercises, learn at your own pace, and practice responsibly.

🚀 How to Use This Lab

Step 1: Explore the Lessons

Browse the Linux and Python folders to find practical exercises.

Step 2: Get Your Own Copy

Click the Fork button at the top of this repository to create your own copy under your personal GitHub account.

Step 3: Open Your Workspace

Open your copied repository and create a Codespace using your own GitHub account.

Step 4: Practice

Follow the lesson instructions and run the exercises in your own workspace.

Important Notes

- You do not need access to the owner's GitHub account.
- Your Codespaces usage belongs to your own account.
- Free usage is subject to GitHub's monthly quotas and limits.
- Practice only on systems you own or have permission to test.
